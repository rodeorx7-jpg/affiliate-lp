# 画像の追加について

このフォルダに、以下のファイル名で画像を追加すると、LP（`kids-uv/index.html`）に自動的に反映されます。
ファイル名は変更しないでください（HTML側で名前を指定しているため）。

| ファイル名 | 使用箇所 | 内容の目安 |
|---|---|---|
| `01-hero.jpg` | SECTION1 ファーストビュー | UVカットサファリハットをかぶった子ども（大きく表示） |
| `02-neck.jpg` | SECTION3 解決策 | 首元・顔まわりのカバー範囲がわかる写真 |
| `03-park.jpg` | SECTION4 外遊び | 公園で遊ぶ子ども |
| `04-water.jpg` | SECTION5 水遊び | 水遊びをする子ども |
| `05-features.jpg` | SECTION6 商品の特徴 | 商品単体の写真（平置きなど） |
| `06-mother.jpg` | SECTION7 ママ目線 | 子どもを見守る母親 |
| `07-cta.jpg` | SECTION11 最終CTA | 夏のお出かけを楽しむ親子 |

画像がまだない間は、この場所に薄い水色の「画像準備中」の枠が表示されます。
