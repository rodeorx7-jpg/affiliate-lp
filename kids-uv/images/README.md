# 画像の追加について

このフォルダに、以下のファイル名で画像を追加すると、LP（`kids-uv/index.html`）に自動的に反映されます。
ファイル名は変更しないでください（HTML側で名前を指定しているため）。

| ファイル名 | 使用箇所 | 内容の目安 |
|---|---|---|
| `01-problem.jpg` | SECTION1 ファーストビュー | 秋の公園でUVカットサファリハットをかぶって遊ぶ子ども（大きく表示） |
| `02-neck.jpg` | SECTION2 顔だけで大丈夫？ | 首元・顔まわりのカバー範囲がわかる写真 |
| `03-park.jpg` | SECTION3 秋の公園 | 秋の公園でお散歩・外遊びする親子 |
| `04-outing.jpg` | SECTION4 秋の行楽 | 遠足・紅葉狩りなど秋の行楽シーン |
| `05-features.jpg` | SECTION5 5つの特徴 | 商品単体の写真（カラーバリエーションが分かるとなお良い） |
| `06-mother.jpg` | SECTION6 ママ目線 | 子どもに帽子をかぶせてあげる母親 |
| `07-cta.jpg` | SECTION10 最終CTA | 秋のお出かけを楽しむ親子 |

画像がまだない間は、この場所に薄いベージュの「画像準備中」の枠が表示されます。
画像は `width: 100%; height: auto;` で表示されるため、トリミングされず縦横比そのままで表示されます。
