# 画像について

以下の7枚は、見出し・アイコン・サイズ表・カラー・CTAボタンなどが画像内にデザインされた完成グラフィックです。
そのため `kids-uv/index.html` では、各画像をそのまま大きく（トリミングなし）表示し、画像内のCTAボタンは押せないため、実際に押せる楽天市場ボタンをHTML側に別途配置しています。

| ファイル名 | 内容 |
|---|---|
| `01-problem.png` | 「子どもの日焼け、顔だけで大丈夫？」（ファーストビュー） |
| `02-neck.png` | 「首元まで、しっかりUV対策。」（首元カバーの訴求） |
| `03-park.png` | 「秋の公園遊びも、UV対策を。」 |
| `04-outing.png` | 「秋のお出かけにも、日差し対策を。」（ハイキング・紅葉狩り・旅行） |
| `05-features.png` | 「うれしい5つのポイント」＋サイズ・カラー一覧 |
| `06-mother.png` | 「涼しくなっても、紫外線対策は忘れずに。」（ママ目線） |
| `07-cta.png` | 「秋のお出かけに。子どものUV対策を。」（最終CTA） |

画像が読み込めない場合は、自動的に薄いベージュの「画像準備中」の枠に切り替わり、レイアウトは崩れません。
